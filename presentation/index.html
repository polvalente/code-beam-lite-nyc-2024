What is Nx?

  • Numerical computing library for Elixir
  • Inspired by NumPy, JAX, and TensorFlow
  • Enables fast, multi-dimensional array operations
  • Supports CPU, GPU, and distributed computation
  • Foundation for machine learning and scientific computing in Elixir

Nx Example: add(cos(x), sin(y))

defmodule Example do
  import Nx.Defn

  defn my_fun(x, y) do
    Nx.add(Nx.cos(x), Nx.sin(y))
  end
end

# Example call:
Example.my_fun(0.0, 1.57)

How computers represent images

Visual:
TODO: manim static RGBA cube rendering goes here
Explanation:
  • Images are represented as 3D arrays (height × width × channels)
  • Each channel (R, G, B, A) is a matrix of values
  • Stacking these matrices forms the full image
  • RGBA: Red, Green, Blue, Alpha (transparency)

Convolution

Visual:
TODO: manim animation of kernel sliding over 4x4 matrix goes here
Explanation:
  • Convolution applies a small matrix (kernel) to each region of the image
  • Each output value is a weighted sum of neighboring pixels
  • Used for edge detection, blurring, sharpening, etc.
  • Often uses zero-padding to keep output size consistent
